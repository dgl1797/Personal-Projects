## [Not Just a Todo Application - NJ-Todo](https://github.com/dgl1797/Personal-Projects/tree/NJ-Todo)
**Used Tech:**
- Angular with TailwindCSS
- Java SpringBoot
- Python websocket and asyncio
- MySQL
- Redis
- MongoDB
- AI Integration in Development Workflow
***
**Description:**<br>
A project aiming to develop a management system for organizing work and projects, tasks assignments within a project, and live chat with available collegues. Live chat is implemented and distributed across Python Servers through asyncio and websocket, using Redis as a coordinator. Access and Management System are implemented using Java for a more consistent payload checking and interaction with MySQL.

The main learning goals achieved with this project were:
- Learning basics-to-advanced Frontend development with Angular and TailwindCSS
- Furhter exploration of session and authentication management techniques in distributed web applications consisting of multiple potential replicas
- Deeper learn of Java-based Servers with SpringBoot, JPAs, Servlets, and interaction with multiple DBMSs
- Development of a scalable and reliable Chat Service with a centralized Redis-based Orchestrator and multiple replicas of Python-based WebSocket chat servers collecting information about connected users distributed among the multiple replicas
- Organized messaging system between servers to discover and correctly deliver messages to destination nodes
- Organizing nodes and replicas within Docker with a live-programming environment where base images are re-used to configure different nodes, organize them in networks, and allow VS-Code attatchment for live programming directly from within the container
- Docker-based load-balancing using different entrypoint modes like VIP (in java servers) and DSNRR (in python servers)
- Integrating AI Agent skills and tools to help and speedup repetitive development phases

## [Shadow Casting Algorithm in PyGame](https://github.com/dgl1797/Personal-Projects/tree/PySnake)
**Used Tech:**
- Python with PyGame
***
**Description:**<br>
Using PyGame to handle UI and graphics, the project is an implementation of the shadow casting algorithm where a point (the player) casts a radius sight configurable from .conf file. In this application the main player is represented by the cursor which casts a sight circle with a radius that depends from the reported value in the config file, then there are two main objects: shadow casting objects (blue), and non-shadow casting ones (light-blue) that may model other players within the 2D map. There is an initial setup stage where objects are placed around the map, and a usage stage where the cursor start casting the sight radius and the shadows generated by the objects around the map.

The main learning goals achieved with this project were:
- Further explore PyGame library and Game Development aspects
- Learning the shadow casting algorithm which is one of the core algorightms in Real Time Strategy games where obstacles must not allow the player to uncover blocked areas from the fog-of-war
- Setup an environment that allows application and learning of multiple algorithms specific for game-development.
